# Crime Risk Analysis & Prediction System

An AI-powered crime analytics platform that analyzes historical crime data across Karnataka and predicts district-level crime risk trends using machine learning.

## Features

- Crime Risk Prediction using Machine Learning
- District-wise Crime Analysis
- Interactive Crime Heatmaps
- Bengaluru Crime Hotspot Visualization
- Crime Category Trend Analysis
- Data-Driven Crime Vulnerability Index (DCVI)
- Streamlit Dashboard for Real-Time Insights

## Installation

Clone the repository

```bash
git clone https://github.com/vishalb999/Crime-Risk-Analysis.git
cd Crime-Risk-Analysis
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
